# LingoCraft

Learn Japanese and French through Minecraft photography, offline pronunciation, and a shared Field Journal.
 Built for **Minecraft Java 1.21.1**, **Java 21**, **Fabric Loader 0.16.9**, and **Fabric API 0.107.0+1.21.1**.

## Install

Download **lingocraft-0.31.1.jar** from the [v0.31.1 release](https://github.com/thepoppfish/LingoCraft/releases/tag/v0.31.1) and place it beside Fabric API in your Minecraft instance’s `mods` folder.
 Replace any older LingoCraft JAR; keep your existing `language-camera` folder, photos, Study files, and settings.

Choose **G → Settings → Language profile → French → Download French**.
 French covers **2,989 supported concepts with 2,980 offline recordings**, with no pronunciation holds.
 Japanese remains available through **Download Japanese**; its one-time **50.3 MiB** pack contains **2,989 lessons and recordings**.
 After installation, vocabulary, pronunciation, and credits work offline.
 Each language keeps separate photos, Field Journal progress, due dates, and Study goals.
 Updates are optional and explicitly requested.

For manual installation, download **LingoCraft-Japanese-0.23.0.zip** and **japanese.json** from the [Japanese release](https://github.com/thepoppfish/LingoCraft/releases/tag/v0.30.1), keep them together, then choose **Install Japanese from file…** in setup.
 Do not unzip the pack or put it in `mods`.

## Play

Use `/languagecamera phone` to obtain the phone.
 Hold it and right-click, or press **V**, to aim.
 Left-click photographs; **R** plays pronunciation; **G** opens the album.
 Aim upward for automatic sky/weather detection.
 Zoom with the scroll wheel or **= / -**.

Right-click a physical **Field Journal** (obtain one with `/languagecamera journal`) or choose **G → Field Journal** to study.
 Both share the same saved learning progress.
 The album’s Settings control tooltips, photo size, language profiles, and pack setup.
 Choose **Check for language updates** there to check the selected language explicitly.
 Setup shows download progress and an installed confirmation, and blocks repeat downloads.
 Existing Japanese installations retain their pack.

Supported multiplayer servers need the core mod and its normal dependencies.
 Each client installs its chosen language locally; the server needs no language audio.

 Model, voice, source, and redistribution notices are included in its ZIP.
 Difficult untranslated names have documented supplemental readings; some checked word assemblies have audible pauses.
 Automated checks do not certify perfect accent or naturalness.
 For manual French setup, keep `LingoCraft-fr_fr-0.1.0.zip` and its matching `.json` from v0.31.1 together, then choose **Install language from file…**.
